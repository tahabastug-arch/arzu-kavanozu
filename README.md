# 🏺 Arzu Kavanozu

**Arzu Kavanozu** is a browser-based application that lets you explore personal preferences across different categories, customize your responses with colors, and export your results as images.

🔗 **Live Demo:** [Open Arzu Kavanozu](https://tahabastug-arch.github.io/arzu-kavanozu/)  
🌌 **Sister Project:** [Explore Kozmik Bahçe](https://tahabastug-arch.github.io/kozmik-bahce/)

---

## ✨ Features

- 📊 28 preference jar categories
- ⭐ Rating system from 1 to 5
- 🎨 Customizable colors
- 🎛️ RGB and HEX color controls
- ✍️ Personalized user name
- 💾 Local browser storage
- 📤 PNG image export and sharing on supported devices
- 📱 Responsive design for desktop and mobile devices

---

## 🚀 How to Use

1. 🌐 Open the live demo.
2. 📋 Explore the categories and enter your ratings.
3. 🎨 Customize the colors and user name if desired.
4. 💾 Export and save your results using the available options.

---

## 💻 Technologies

- 🌐 HTML
- 🎨 CSS
- ⚡ JavaScript
- 💾 Browser Local Storage API
- 🖼️ Canvas API

---

## 🔒 Privacy

Based on a static review of the current application code, no application-level mechanism for sending user responses to an external server was identified. Responses are stored locally in the browser using `localStorage`.

This statement does not cover hosting provider access logs or external applications used for sharing. Exported images may contain personal responses, so review them before sharing.

# 🇹🇷 Türkçe

**Arzu Kavanozu**, kişisel tercihlerini farklı kategorilerde değerlendirmeni, yanıtlarını renklerle kişiselleştirmeni ve sonuçlarını görsel olarak dışa aktarmanı sağlayan tarayıcı tabanlı bir uygulamadır.

## Özellikler

- 📊 28 farklı tercih kavanozu kategorisi
- ⭐ 1–5 arasında puanlama sistemi

- 🎛️ RGB ve HEX renk kontrolleri
- ✍️ Kullanıcı adıyla kişiselleştirme

## Gizlilik

Mevcut uygulama kodunun statik incelemesinde, kullanıcı yanıtlarını harici bir sunucuya gönderen bir uygulama mekanizması tespit edilmemiştir. Yanıtlar tarayıcının yerel depolama alanında (`localStorage`) saklanır.

Bu açıklama, barındırma sağlayıcısının erişim kayıtlarını veya paylaşım için kullanılan harici uygulamaları kapsamaz. Dışa aktarılan görseller kişisel yanıtlar içerebileceğinden, paylaşmadan önce içeriklerini kontrol etmeni öneririz.
